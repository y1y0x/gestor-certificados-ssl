Servicios adicionales (Add-ons)

Complementa tu plan base con servicios especializados de monitoreo híbrido, SOC gestionado, seguridad avanzada y AppSec. Se contratan sobre cualquier plan, incrementando el ticket promedio entre 30-50%.

Z
Monitoreo Avanzado
Zabbix · Monitoreo híbrido on-prem + Azure
Plataforma de monitoreo empresarial para servidores físicos, switches, bases de datos y aplicaciones legacy que no pueden monitorearse solo con Azure Monitor. Ideal para entornos híbridos.
USD 150 - 300 / mes
Open Source
  • Instalación y configuración de Zabbix server + proxies
  • Monitoreo de red, servidores físicos, switches y firewalls
  • Dashboards personalizados y alertas multi-canal
  • Hasta 100 hosts monitoreados (plan base)
  • Reportes ejecutivos de disponibilidad mensual
W
SOC Gestionado Popular
Wazuh · SIEM + XDR open source
Centro de Operaciones de Seguridad gestionado con Wazuh. Ideal para clientes regulados que necesitan cumplimiento (ISO 27001, PCI DSS, GDPR), detección de amenazas y auditoría continua.
USD 250 - 500 / mes
Open Source Alto valor
  • SIEM y XDR con detección de intrusiones en tiempo real
  • File Integrity Monitoring (FIM) y log analysis
  • Monitoreo 24x7 por equipo SOC certificado
  • Reglas de compliance preconfiguradas (PCI, GDPR, ISO)
  • Reporte mensual de incidentes y respuesta básica
D
Defender for Cloud Premium
Seguridad nativa avanzada de Microsoft
Gestión avanzada de Microsoft Defender for Cloud P2 con hardening proactivo, threat intelligence, protección Just-In-Time y escaneo de vulnerabilidades integrado. (Incluido en plan Business; este add-on habilita P2 en Essential).
USD 100 - 200 / mes
Premium
  • Activación de Defender P2 (servidores, containers, SQL, storage)
  • Hardening y remediación proactiva de recomendaciones
  • Acceso Just-In-Time a VMs de producción
  • Escaneo de vulnerabilidades con Qualys integrado
  • Monitoreo de amenazas y respuesta a incidentes
O
AppSec (OWASP ZAP)
Escaneo de vulnerabilidades web
Pruebas de seguridad DAST sobre aplicaciones web públicas con OWASP ZAP. Detecta OWASP Top 10 (SQL Injection, XSS, Broken Auth) en apps desplegadas en Azure App Service, AKS o VMs.
USD 200 / escaneo ó USD 150 / mes
Open Source
  • Escaneos automatizados trimestrales con OWASP ZAP
  • Detección de OWASP Top 10 y vulnerabilidades críticas
  • Reporte ejecutivo + técnico con priorización CVSS
  • Integración con pipelines CI/CD (DevSecOps)
  • Re-test post-remediación incluido

Alcance y reglas comerciales

ConceptoDefinición sugerida
Starter — AlcanceServicio 100% automatizado. No incluye cambios de configuración, atención a aplicaciones ni consultoría. Solo monitoreo, alertas, parches automáticos y verificación de backups.
Add-onsContratados sobre cualquier plan (excepto Defender Premium que requiere mínimo Essential). Facturación mensual independiente del plan base.
Infraestructura Add-onsZabbix y Wazuh requieren 1 VM dedicada (no incluida en fee) que se suma al consumo Azure del cliente. OWASP ZAP puede ejecutarse desde infraestructura del CSP.
Horas excedentesStarter: USD 120/h · Essential/Business: USD 90/h · Enterprise: USD 120/h.
Migración automáticaStarter migra a Essential si el consumo supera USD 400/mes por 3 meses consecutivos.
Proyectos fuera del planMigraciones, AKS, landing zones, automatización avanzada se cotizan como proyecto separado.
